# Le référentiel Agona

La méthode d'Agona, publiée. Grille de revue de code, consigne de
développement, barèmes et livret : les documents remis aux apprenants au
démarrage d'une promotion, réunis ici pour être repris et adaptés.

Agona est une formation où des développeurs, aspirants et juniors, passent
11 semaines sur une problématique réelle d'entreprise. Le programme, le
déroulé et le contexte sont sur https://agona.dev.

## Les documents

| Fichier | Ce qu'il contient |
| --- | --- |
| [grille-de-revue.md](grille-de-revue.md) | Les 10 critères de la revue de code, sur 35 points, et les 3 failles lourdes. |
| [consigne-developpement.md](consigne-developpement.md) | Ce qu'on attend des apprenants pendant un sprint. |
| [bareme-soutenance.md](bareme-soutenance.md) | Le barème de l'oral, sur 35 points. |
| [guide-peer-review.md](guide-peer-review.md) | Le protocole d'évaluation par les pairs, sur 30 points. |
| [livret-progression.md](livret-progression.md) | Le dossier individuel de compétences, et les douze objectifs. |

Un sprint vaut 100 points : la revue de code (35), la soutenance (35) et la
peer-review (30).
